Tipps & TricksTips & tricks.

Kleine Erkenntnisse aus meinem Alltag als Admin, jeweils in einer Minute gelesen. Small lessons from my day-to-day work as an admin, each one read in a minute.

FirewallFirewall

Erst den Rückweg sichernSecure your way back first

Bevor Sie Firewall-Regeln ändern, klären Sie, wie Sie wieder hineinkommen: Konfiguration sichern, Konsolenzugang bereithalten und die Regel für den eigenen Admin-Zugang zuletzt anfassen. Wer sich aussperrt, steht sonst vor der eigenen Mauer.Before changing firewall rules, make sure you can get back in: back up the configuration, keep console access ready and touch the rule for your own admin access last. Otherwise you end up locked out behind your own wall.

FirewallFirewall

Die erste passende Regel gewinntThe first matching rule wins

Die Firewall prüft ihre Regeln von oben nach unten. Beim ersten Treffer ist Schluss, alles darunter wird für dieses Paket nicht mehr angesehen. So arbeiten zum Beispiel die Interface-Regeln in OPNsense. Deshalb gehören spezielle Regeln nach oben und allgemeine nach unten.The firewall checks its rules from top to bottom. The first match ends the search; nothing below it is looked at for that packet. This is how the interface rules in OPNsense work, for example. That is why specific rules belong at the top and general ones at the bottom.

FirewallFirewall

VPN statt PortfreigabeVPN instead of port forwarding

Jede Portfreigabe stellt einen Dienst direkt ins Internet. Besser ist ein VPN wie WireGuard auf der Firewall: Nach außen ist nur ein UDP-Port offen, und an die internen Dienste kommt nur, wer einen gültigen Schlüssel hat.Every port forward exposes a service directly to the internet. A VPN such as WireGuard on the firewall is better: only one UDP port is open to the outside, and only someone with a valid key reaches the internal services.

NetzwerkNetwork

169.254.x.x heißt: kein DHCP169.254.x.x means: no DHCP

Hat ein Gerät eine Adresse aus 169.254.0.0/16, hat es keinen DHCP-Server erreicht und sich selbst eine Adresse gegeben (APIPA, typisch bei Windows und macOS). Die Netzwerkkarte ist dann selten schuld. Erst Kabel, VLAN-Zuordnung des Ports und DHCP-Server prüfen.If a device has an address from 169.254.0.0/16, it did not reach a DHCP server and gave itself an address (APIPA, typical on Windows and macOS). The network card is rarely to blame. Check the cable, the port's VLAN assignment and the DHCP server first.

NetzwerkNetwork

Pro Switchport nur ein untagged VLANOnly one untagged VLAN per switch port

Auf einem Port können viele VLANs tagged laufen, aber Pakete ohne Tag landen immer in genau einem VLAN, der PVID. Sind zwei VLANs untagged auf einem Port eingetragen, ist unklar, wohin solche Pakete gehören. Das ist ein klassischer Konfigurationsfehler.Many VLANs can run tagged on one port, but untagged frames always land in exactly one VLAN, the PVID. If two VLANs are set as untagged on one port, it is unclear where such frames belong. That is a classic configuration mistake.

LinuxLinux

Wer lauscht auf welchem Port?Who is listening on which port?

Der Befehl zeigt alle Dienste, die auf TCP oder UDP auf Verbindungen warten, mit Port und Programmname. Für den Programmnamen braucht es root-Rechte. Ideal, um vor einer Portfreigabe zu prüfen, was wirklich läuft.This command lists every service waiting for TCP or UDP connections, with port and program name. Showing the program name requires root. Ideal for checking what is really running before you open a port.

sudo ss -tulpn
WindowsWindows

Ist der Port erreichbar?Is the port reachable?

In der PowerShell prüft Test-NetConnection, ob ein TCP-Port auf einem Zielrechner antwortet. Telnet muss dafür nicht installiert sein. Steht bei TcpTestSucceeded „False“, ist der Port zu oder wird von einer Firewall gefiltert. UDP lässt sich damit nicht testen.In PowerShell, Test-NetConnection checks whether a TCP port answers on a target host. Telnet does not need to be installed. If TcpTestSucceeded shows “False”, the port is closed or filtered by a firewall. It cannot test UDP.

Test-NetConnection srv01 -Port 443
BackupBackup

Ein Snapshot ist kein BackupA snapshot is not a backup

Ein Snapshot liegt auf demselben Speicher wie die VM. Fällt die Platte aus, sind VM und Snapshot gemeinsam weg. Snapshots sind ideal als schneller Rückweg vor einem Update. Ein Backup gehört auf ein anderes Gerät, zum Beispiel ein NAS oder einen Proxmox Backup Server.A snapshot lives on the same storage as the VM. If the disk fails, VM and snapshot are gone together. Snapshots are ideal as a quick way back before an update. A backup belongs on a separate device, such as a NAS or a Proxmox Backup Server.
